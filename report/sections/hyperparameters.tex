Table~\ref{tab:hyperparameters} lists the training settings of every run whose
results appear in this report, as recorded in each run's resolved
\texttt{config.yaml} in the repository.

Three learning rates appear, none tuned for this problem. Adam uses its
authors' default of $10^{-3}$ wherever a network trains from scratch or only a
new prediction layer is trained, and SGD uses the common starting value
$10^{-2}$ (Section~\ref{sec:optimizer-comparison}). Full fine-tuning uses
$10^{-4}$, below the frozen-head rate, to limit changes to the pretrained
filters (Section~\ref{sec:sota-protocol}).
