\subsection{Preprocessing and augmentation}
\label{sec:data-preparation}

\paragraph{Standardisation.}
Each RGB channel is standardised as
\begin{equation}
  x'_c = \frac{x_c-\mu_c}{\sigma_c},
  \label{eq:standardisation}
\end{equation}
where pixel values are first scaled to $[0,1]$, and $\mu_c$ and $\sigma_c$
denote the mean and population standard deviation of channel $c$. The
statistics are computed from the EuroSAT training split and the same values
are then applied to the training, validation, and test sets. This places the
three colour channels on a comparable scale before they enter the network. The
same EuroSAT-derived statistics are also used for the pretrained models in
Task~5. Although those models were originally trained on ImageNet using
ImageNet channel statistics~\cite{deng2009imagenet}, using a common EuroSAT
preprocessing pipeline keeps the input treatment consistent across the models
being compared.

\paragraph{Statistics from the training set only.}
The normalisation statistics are estimated only from the training partition.
Computing $\mu_c$ and $\sigma_c$ over all 27,000 images would allow
information from the validation and test sets to influence preprocessing,
which would weaken the independence of the final evaluation. The split is
therefore fixed first, after which the channel means and standard deviations
are calculated from the training images only, using the native-resolution
images before augmentation. These same values are then applied unchanged to
the validation and test sets. The statistics are cached after computation so
that every experiment uses the same normalisation values.

\paragraph{Augmentation.}
Data augmentation is applied only to the training set. Each training image is
independently subjected to a horizontal flip with probability 0.5, a vertical
flip with probability 0.5, and a rotation chosen uniformly from $0^\circ$,
$90^\circ$, $180^\circ$, and $270^\circ$. These transformations are sampled
again each epoch, producing the eight possible orientations of a square image
over time (Figure~\ref{fig:data-augmentation-grid}).

These operations preserve the EuroSAT class labels because the images are
captured from an overhead viewpoint, where image orientation has no fixed
physical meaning. A highway, river or crop field remains the same land-cover
class after rotation or reflection. Restricting rotations to multiples of
$90^\circ$ also avoids interpolation and padding, since the transformation
only rearranges pixels on the square image grid.

Other common augmentations were not used. Random cropping and rescaling can
alter the apparent scale of structures and may remove useful content from the
small $64\times64$ images. Colour jitter was also avoided because colour and
spectral appearance help distinguish classes such as vegetation, water, and
bare or built-up surfaces.

\paragraph{Evaluation preprocessing and class balance.}
Validation and test images are converted to tensors and standardised using
the statistics computed from the training set, with no random augmentation
applied. This keeps the evaluation inputs fixed and makes evaluation deterministic. With class sizes
ranging from 2,000 to 3,000 images (Table~\ref{tab:dataset-split}), EuroSAT has a mild class imbalance. There was no under sampling or
synthetic minority generation used since the
largest class is only 1.5 times the size of the smallest. Stratified splitting preserves the
same class proportions across the training, validation, and test sets, while
macro averaged precision and recall are reported together with accuracy so
that performance on smaller classes contributes equally to the evaluation.
